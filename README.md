## What this is

One haiku about debugging, three lines in the 5-7-5 syllable shape, at most 200 characters:

> three am, cursor blinks
> the log says nothing is wrong
> so it must be me

## How it works

`main.py` (Python 3.13, no network, deterministic) writes the haiku to `/output/entry.txt`.

```bash
python3 main.py
```
